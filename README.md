# Maranatha Papelería Creativa

Sitio web oficial y catálogo interactivo de **Maranatha Papelería Creativa**, taller de autor en Cali (Valle del Cauca, Colombia) especializado en cajas temáticas, dulceros para eventos, cake toppers 3D, stickers personalizados troquelados, vinilos e insumos de papelería.

---

## Tecnologías Utilizadas

- **Frontend:** React 18
- **Enrutamiento:** React Router DOM (v7)
- **Estilos:** Tailwind CSS
- **Iconografía:** Lucide React
- **Herramienta de Construcción:** Vite
- **Despliegue y CDN:** Cloudflare Pages

---

## Instalación y Desarrollo Local

1. Clonar el repositorio:
```bash
git clone https://github.com/Juanpa571/Maranatha.git
cd Maranatha
```

2. Instalar dependencias:
```bash
npm install
```

3. Iniciar el servidor local de desarrollo:
```bash
npm run dev
```

4. Compilar para producción:
```bash
npm run build
```

## Estructura del Proyecto

```text
├── public/                 # Assets estáticos (catálogo optimizado, favicons, robots.txt, sitemap.xml)
├── src/
│   ├── components/         # Componentes modulares de interfaz y catálogo
│   ├── data/               # Información estructurada de productos y categorías (categoriesData.js)
│   ├── pages/              # Páginas principales (Home, Catálogo, Categorías, Legales)
│   ├── App.jsx             # Enrutador y layout global
│   └── main.jsx            # Punto de entrada de la aplicación
├── index.html              # Shell HTML con metadatos SEO y Schema.org LocalBusiness
├── tailwind.config.js      # Configuración de diseño y paleta de colores
└── vite.config.js          # Configuración de empaquetado Vite
```
